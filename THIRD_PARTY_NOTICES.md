bopl-port itself is MIT OR Apache-2.0. The release archives ship this file
plus a `licenses/` folder with the full texts listed below.

## Not part of this project

Bopl Battle, its art, sounds, music, levels and code are (c) Johan Grönvall
and the Bopl Battle developers. bopl-port contains none of it and is not
affiliated with them; players import the data from their own copy at first
start. `scripts/check-no-game-data.sh` (run in CI) keeps images, audio, Unity
files, assemblies, decompiled code and replays out of the repository and the
release archives.

## Bundled in the binary

- **Noto Sans Bold** (`crates/render/assets/fonts/`), (c) Google LLC, SIL Open
  Font License 1.1. Used for the renderer's built-in development text.
  License text: `licenses/OFL.txt`.
- **FMOD Vorbis setup headers** (`crates/unity/data/fsb5_vorbis_setup.bin`),
  generated by `scripts/dev/gen_fsb_vorbis_setup.py` from the table of
  [fsbex](https://github.com/astral4/fsbex) (MIT OR Apache-2.0). The headers
  are standard libvorbis encoder setup headers (libvorbis: BSD-3-Clause,
  (c) Xiph.Org Foundation), needed to decode FSB5 Vorbis streams of the
  player's own install.
- **Unity type layouts** (`crates/unity/typetrees/`): field names, types and
  alignment flags that the asset reader needs because the game's files are
  built without type trees; generated by `scripts/dev/gen_typetrees.py` with
  [UnityPy](https://github.com/K0lb3/UnityPy) (MIT) from its type-tree
  database (engine classes) and its TypeTreeGenerator (the game's
  MonoBehaviour classes). They contain no asset data.
- **Rust crates**: every crate linked into the binary (wgpu, naga, sdl2,
  lewton, fontdue, png, serde, ggrs, warpzone-core, ... and their
  dependencies, about 220 in total) with its license text is listed
  in `licenses/RUST_DEPENDENCIES.txt`, generated per release and per target
  by `packaging/gen-licenses.py` from `cargo metadata`. All are permissive
  (MIT, Apache-2.0, BSD-2/3-Clause, ISC, Zlib, Unicode-3.0,
  CDLA-Permissive-2.0, Unlicense, 0BSD);
  the script fails the packaging if a copyleft license without an
  alternative shows up.

## Dynamically linked

- **SDL2** (https://libsdl.org), zlib license, (c) Sam Lantinga and
  contributors.
  - Linux: the system's `libSDL2-2.0.so.0` is used. A package built with
    `scripts/package-linux.sh --bundle-sdl` carries that library in `lib/`
    together with `licenses/SDL2-LICENSE.txt`.
  - Windows: the official SDL2 2.32.10 mingw release `SDL2.dll` ships next to
    `bopl-port.exe`; license text in `licenses/SDL2-LICENSE.txt`.

## Windows runtime

The Windows executable is cross-compiled with
[llvm-mingw](https://github.com/mstorsjo/llvm-mingw) and statically contains
the mingw-w64 C runtime (public domain / ZPL 2.1), LLVM's libunwind and
compiler-rt builtins (Apache-2.0 WITH LLVM-exception) and the Rust standard
library (MIT OR Apache-2.0).

## Online play

Online play uses [Warpzone](https://github.com/jarvis-jhk/warpzone)
(`warpzone-core`, linked as a Rust crate) and
[GGRS](https://github.com/gschup/ggrs) (MIT OR Apache-2.0) for rollback; both
are listed in `licenses/RUST_DEPENDENCIES.txt`.
